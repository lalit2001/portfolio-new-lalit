### What Are Design Patterns?

Design patterns are **proven, reusable solutions to common programming problems**. They’re like architectural blueprints that show:

- **What** — The core problem being solved
- **How** — The structure and relationships of objects
- **When** — Situations where the pattern applies
- **Why** — Benefits and trade-offs

Think of them like recipes in cooking:

- A recipe is a proven way to make a dish
- You adapt it to your ingredients and taste
- You don’t reinvent recipes from scratch each time

Design patterns are to software what recipes are to cooking.

### Why You NEED Design Patterns for Agentic Systems

### 1. Multiple Integrations are Inevitable

Agentic systems are inherently complex:

- **Multiple databases**: Structured (PostgreSQL), document (MongoDB), vector (Pinecone), cache (Redis)
- **Multiple LLMs**: OpenAI, Anthropic, Ollama, local models, future models
- **Multiple platforms**: Cloud, local, Docker, Kubernetes
- **Multiple interfaces**: REST API, WebSocket, CLI, web UI

Without patterns, each new integration means rewriting core logic.

**With patterns**: Add a new database in one file, add a new LLM in one file.

### 2. Agents Need Flexibility

Users want to:

- Switch LLMs based on cost/performance
- Scale to different databases
- Deploy on different platforms
- Enable different features (logging, caching, etc.)

Without patterns, each change requires code modifications and testing.

**With patterns**: Configuration files determine behavior. Zero code changes needed.

### 3. Agentic Systems Are Complex

AI agents involve:

- State management (idle, thinking, responding, error)
- Task coordination (sequential, parallel, hierarchical)
- Event handling (user input, response generation, errors)
- Memory management (conversation history, context, embeddings)
- Resource sharing (LLM instances, database connections)

Without patterns, complexity becomes **exponential**.

**With patterns**: Each pattern handles one aspect cleanly.

### 4. Testing and Debugging Become Nightmare

When everything is tightly coupled:

``` python

# ❌ Can't test agent logic without real database
# ❌ Can't test database logic without real LLM
# ❌ Can't test LLM without paying for API calls
# ❌ Finding bugs means debugging across multiple files
```

**With patterns**: Mock implementations allow testing in isolation.

### 5. Team Scalability

Without patterns:

- Every developer has their own approach
- Code review takes forever (inconsistent style)
- Onboarding is painful (no standard structure)
- Integration conflicts are common

**With patterns**: Everyone follows the same blueprint.

### How to Use Design Patterns

### Step 1: Identify Your Problem

Look at your codebase and ask:

- **Is there duplicated logic?** → Use patterns to extract common behavior
- **Are objects tightly coupled?** → Use patterns to decouple them
- **Is code hard to test?** → Use patterns to isolate concerns
- **Will this need to scale?** → Use patterns that allow extension

### Step 2: Find the Right Pattern(s)

Use this decision guide:

``` python

Problem Type        Solution Pattern(s)
────────────────────────────────────────
Multiple object types → Factory Method, Abstract Factory
Complex construction → Builder
Single instance needed → Singleton
Incompatible interfaces → Adapter
Decouple layers → Bridge
Tree structures → Composite
Add features → Decorator
Complex subsystem → Facade
Control access → Proxy
Sequential decisions → Chain of Responsibility
Encapsulate actions → Command
Sequential access → Iterator
Object communication → Mediator
Save state → Memento
Notify observers → Observer
Change behavior → State, Strategy
Define skeleton → Template Method
Transform structures → Visitor
```

### Step 3: Implement the Pattern

``` python

# 1. Identify the abstraction (interface)
class DatabaseConnection(ABC):
    @abstractmethod
    def save(self, data): pass

# 2. Create concrete implementations
class PostgreSQL(DatabaseConnection):
    def save(self, data): # postgresql specific code
class MongoDB(DatabaseConnection):
    def save(self, data): # mongodb specific code
# 3. Create factory for instantiation
class DatabaseFactory:
    @staticmethod
    def create(db_type):
        if db_type == "postgres": return PostgreSQL()
        if db_type == "mongodb": return MongoDB()
# 4. Use abstraction in your code
db = DatabaseFactory.create(config.db_type)
db.save(data)  # Works with any database
```

### Step 4: Extend Without Modification

Adding a new database is now trivial:

``` python

# Just add one new class
class Elasticsearch(DatabaseConnection):
    def save(self, data): # elasticsearch specific code

# Register it
DatabaseFactory.register("elasticsearch", Elasticsearch)
# Your agent code doesn't change at all!
```

### Step 5: Test with Mocks

``` python

# Create mock for testing
class MockDatabase(DatabaseConnection):

        self.saved_data = data

# Test your agent logic
```

### When NOT to Use Patterns

Patterns aren’t always necessary. Don’t use them if:

1.  **Project is tiny** (\< 500 lines)

- Small scripts don’t need patterns
- Patterns add unnecessary complexity

**2. No future extensibility needed**

- One LLM, one database, one use case
- Patterns trade complexity now for flexibility later

**3. Performance is critical**

- Some patterns add overhead
- But this is rarely the bottleneck

**4. Over-engineering**

- Using 10 patterns for a 3-pattern problem
- More patterns ≠ better design

**Rule of thumb**: Use patterns when you see duplication or anticipate change.

### CREATIONAL PATTERNS

### 1. Factory Method Pattern

**Purpose:** Create objects without specifying exact classes, allowing subclasses to decide.

**Agentic Use Case:** Different task types create different handlers

``` python

from abc import ABC, abstractmethod

# ============================================
# TASK HANDLER FACTORY METHOD PATTERN
# ============================================
class TaskHandler(ABC):
    """Abstract task handler"""
    
    @abstractmethod
    def execute(self, task_data: dict) -> str:
        pass
    
    @abstractmethod
    def validate(self, task_data: dict) -> bool:
        pass

class ResearchTaskHandler(TaskHandler):
    """Handles research tasks"""
    
    def execute(self, task_data: dict) -> str:
        query = task_data.get("query")
        return f"Researching: {query}... [research results]"
    
    def validate(self, task_data: dict) -> bool:
        return "query" in task_data

class CodeTaskHandler(TaskHandler):
    """Handles code generation tasks"""
    
    def execute(self, task_data: dict) -> str:
        language = task_data.get("language", "python")
        description = task_data.get("description")
        return f"Generating {language} code for: {description}"
    
    def validate(self, task_data: dict) -> bool:
        return "description" in task_data

class EmailTaskHandler(TaskHandler):
    """Handles email composition tasks"""
    
    def execute(self, task_data: dict) -> str:
        recipient = task_data.get("recipient")
        subject = task_data.get("subject")
        return f"Composing email to {recipient} about {subject}"
    
    def validate(self, task_data: dict) -> bool:
        return "recipient" in task_data and "subject" in task_data

class TaskProcessor:
    """Factory class - creates appropriate handler"""
    
    def create_handler(self, task_type: str) -> TaskHandler:
        """Factory method"""
        handlers = {
            "research": ResearchTaskHandler,
            "code": CodeTaskHandler,
            "email": EmailTaskHandler,
        }
        
        handler_class = handlers.get(task_type.lower())
        if not handler_class:
            raise ValueError(f"Unknown task type: {task_type}")
        
        return handler_class()
    
    def process_task(self, task_type: str, task_data: dict) -> str:
        """Create and execute task"""
        handler = self.create_handler(task_type)
        
        if not handler.validate(task_data):
            raise ValueError(f"Invalid task data for {task_type}")
        
        return handler.execute(task_data)

# Usage
processor = TaskProcessor()
result = processor.process_task("research", {"query": "machine learning trends"})
result = processor.process_task("code", {"language": "python", "description": "fibonacci function"})
result = processor.process_task("email", {"recipient": "user@example.com", "subject": "Meeting reminder"})
```

### 2. Abstract Factory Pattern

**Purpose:** Create families of related objects without specifying concrete classes.

**Agentic Use Case:** Different LLM + Database + Memory combinations (already covered in previous article, showing extended version)

``` python

# ============================================
# ABSTRACT FACTORY - AGENT ECOSYSTEM
# ============================================

from abc import ABC, abstractmethod
# Abstract Products
class LLM(ABC):
    @abstractmethod
    def generate(self, prompt: str) -> str:
        pass

class Memory(ABC):
    @abstractmethod
    def store(self, key: str, value: str):
        pass
    
    @abstractmethod
    def retrieve(self, key: str) -> str:
        pass

class Toolkit(ABC):
    @abstractmethod
    def execute_tool(self, tool_name: str, **kwargs) -> str:
        pass

# Concrete Products for OpenAI Ecosystem
class OpenAILLM(LLM):
    def generate(self, prompt: str) -> str:
        return f"[OpenAI Response to: {prompt}]"

class OpenAIMemory(Memory):
    def __init__(self):
        self.storage = {}
    
    def store(self, key: str, value: str):
        self.storage[key] = value
    
    def retrieve(self, key: str) -> str:
        return self.storage.get(key, "")

class OpenAIToolkit(Toolkit):
    def execute_tool(self, tool_name: str, **kwargs) -> str:
        return f"[OpenAI Tool: {tool_name} executed]"

# Concrete Products for Anthropic Ecosystem
class AnthropicLLM(LLM):
    def generate(self, prompt: str) -> str:
        return f"[Claude Response to: {prompt}]"

class AnthropicMemory(Memory):
    def __init__(self):
        self.storage = {}
    
    def store(self, key: str, value: str):
        self.storage[key] = value.upper()  # Store in uppercase
    
    def retrieve(self, key: str) -> str:
        return self.storage.get(key, "")

class AnthropicToolkit(Toolkit):
    def execute_tool(self, tool_name: str, **kwargs) -> str:
        return f"[Claude Tool: {tool_name} executed safely]"

# Abstract Factory
class AgentFactory(ABC):
    @abstractmethod
    def create_llm(self) -> LLM:
        pass
    
    @abstractmethod
    def create_memory(self) -> Memory:
        pass
    
    @abstractmethod
    def create_toolkit(self) -> Toolkit:
        pass

# Concrete Factories
class OpenAIAgentFactory(AgentFactory):
    def create_llm(self) -> LLM:
        return OpenAILLM()
    
    def create_memory(self) -> Memory:
        return OpenAIMemory()
    
    def create_toolkit(self) -> Toolkit:
        return OpenAIToolkit()

class AnthropicAgentFactory(AgentFactory):
    def create_llm(self) -> LLM:
        return AnthropicLLM()
    
    def create_memory(self) -> Memory:
        return AnthropicMemory()
    
    def create_toolkit(self) -> Toolkit:
        return AnthropicToolkit()

# Client
class Agent:
    def __init__(self, factory: AgentFactory):
        self.llm = factory.create_llm()
        self.memory = factory.create_memory()
        self.toolkit = factory.create_toolkit()
    
    def run(self, prompt: str):
        response = self.llm.generate(prompt)
        self.memory.store("last_response", response)
        result = self.toolkit.execute_tool("respond", message=response)
        return result

# Usage
openai_agent = Agent(OpenAIAgentFactory())
openai_agent.run("What is AI?")
anthropic_agent = Agent(AnthropicAgentFactory())
anthropic_agent.run("What is AI?")
```

### 3. Builder Pattern

**Purpose:** Construct complex objects step by step.

**Agentic Use Case:** Build complex agent configurations

``` python

# ============================================
# BUILDER PATTERN - AGENT CONFIGURATION
# ============================================

from typing import List, Dict, Any
class AgentPrompt:
    def __init__(self):
        self.system_prompt = ""
        self.tools_available = []
        self.constraints = []
        self.examples = []
        self.output_format = ""
    
    def __str__(self):
        return f"""
System: {self.system_prompt}
Tools: {self.tools_available}
Constraints: {self.constraints}
Examples: {len(self.examples)} examples
Output Format: {self.output_format}
"""

class AgentPromptBuilder:
    """Builder for complex agent prompts"""
    
    def __init__(self):
        self.agent_prompt = AgentPrompt()
    
    def set_system_prompt(self, prompt: str) -> "AgentPromptBuilder":
        self.agent_prompt.system_prompt = prompt
        return self
    
    def add_tool(self, tool_name: str) -> "AgentPromptBuilder":
        self.agent_prompt.tools_available.append(tool_name)
        return self
    
    def add_constraint(self, constraint: str) -> "AgentPromptBuilder":
        self.agent_prompt.constraints.append(constraint)
        return self
    
    def add_example(self, input_ex: str, output_ex: str) -> "AgentPromptBuilder":
        self.agent_prompt.examples.append({
            "input": input_ex,
            "output": output_ex
        })
        return self
    
    def set_output_format(self, format_spec: str) -> "AgentPromptBuilder":
        self.agent_prompt.output_format = format_spec
        return self
    
    def build(self) -> AgentPrompt:
        return self.agent_prompt

# Usage - Fluent interface
research_agent = (AgentPromptBuilder()
    .set_system_prompt("You are a research expert")
    .add_tool("search_web")
    .add_tool("fetch_document")
    .add_tool("analyze_data")
    .add_constraint("Always cite sources")
    .add_constraint("Provide balanced view")
    .add_example("What is AI?", "AI is the simulation of human intelligence...")
    .set_output_format("JSON with keys: summary, sources, confidence")
    .build())
print(research_agent)
# Another agent with different configuration
coding_agent = (AgentPromptBuilder()
    .set_system_prompt("You are an expert Python developer")
    .add_tool("write_code")
```

### 5. Singleton Pattern

**Purpose:** Ensure only one instance of a class exists globally.

``` python
# ============================================
# SINGLETON PATTERN - GLOBAL RESOURCES
# ============================================

from threading import Lock
class AgentConfigManager:
    """Singleton - manages global agent configuration"""
    
    _instance = None
    _lock = Lock()
    
    def __new__(cls):
        if cls._instance is None:
            with cls._lock:
                # Double-checked locking
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
                    cls._instance._initialized = False
        return cls._instance
    
    def __init__(self):
        if self._initialized:
            return
        self.config = {}
        self.llm_provider = None
        self.db_type = None
        self._initialized = True
    
    def set_config(self, key: str, value):
        self.config[key] = value
    
    def get_config(self, key: str):
        return self.config.get(key)
    
    def set_llm(self, provider: str):
        self.llm_provider = provider
    
    def get_llm(self):
        return self.llm_provider

# Usage

print(f"Temperature: {config2.get_config('temperature')}")  # 0.7

# Pythonic Singleton using decorator
def singleton(cls):
    instances = {}
    
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    
    return get_instance

@singleton
class EventBus:
    """Singleton event bus using decorator"""
    
    def __init__(self):
        self.subscribers = {}
    
    def subscribe(self, event_type: str, handler):
        if event_type not in self.subscribers:
            self.subscribers[event_type] = []
        self.subscribers[event_type].append(handler)
    
    def publish(self, event_type: str, data):
        if event_type in self.subscribers:
            for handler in self.subscribers[event_type]:
                handler(data)

# Usage
bus1 = EventBus()
bus2 = EventBus()
print(f"Same bus: {bus1 is bus2}")  # True
```

``` python
            "tokens_used": length
        }

    """TensorFlow - yet another interface"""
```

### 8. Composite Pattern

**Purpose:** Compose objects into tree structures to represent hierarchies.

**Agentic Use Case:** Composite tasks and sub-tasks

``` python

# ============================================
# COMPOSITE PATTERN - HIERARCHICAL TASKS
# ============================================

from abc import ABC, abstractmethod
from typing import List
class Task(ABC):
    @abstractmethod
    def execute(self) -> str:
        pass
    
    @abstractmethod
    def add_subtask(self, task: "Task"):
        pass
    
    @abstractmethod
    def get_duration(self) -> float:
        pass

class SimpleTask(Task):
    """Leaf node - single task"""
    
    def __init__(self, name: str, duration: float = 1.0):
        self.name = name
        self.duration = duration
    
    def execute(self) -> str:
        return f"Executing: {self.name}"
    
    def add_subtask(self, task: Task):
        raise ValueError("Cannot add subtask to SimpleTask")
    
    def get_duration(self) -> float:
        return self.duration

class CompositeTask(Task):
    """Composite node - contains multiple tasks"""
    
    def __init__(self, name: str):
        self.name = name
        self.subtasks: List[Task] = []
    
    def add_subtask(self, task: Task):
        self.subtasks.append(task)
    
    def execute(self) -> str:
        results = [f"Starting composite task: {self.name}"]
        for subtask in self.subtasks:
            results.append(f"  - {subtask.execute()}")
        results.append(f"Completed: {self.name}")
        return "\n".join(results)
    
    def get_duration(self) -> float:
        return sum(task.get_duration() for task in self.subtasks)

# Build a hierarchy
research_project = CompositeTask("Research Project")
# Add sub-tasks
literature_review = CompositeTask("Literature Review")
literature_review.add_subtask(SimpleTask("Search databases", 2.0))
literature_review.add_subtask(SimpleTask("Read papers", 5.0))
literature_review.add_subtask(SimpleTask("Summarize findings", 1.5))
research_project.add_subtask(literature_review)
# Add more tasks
experiments = CompositeTask("Experiments")
experiments.add_subtask(SimpleTask("Setup environment", 1.0))
experiments.add_subtask(SimpleTask("Run experiments", 10.0))
experiments.add_subtask(SimpleTask("Collect results", 1.0))
research_project.add_subtask(experiments)
research_project.add_subtask(SimpleTask("Write report", 3.0))
# Execute entire hierarchy
print(research_project.execute())
print(f"\nTotal duration: {research_project.get_duration()} hours")
```

### 9. Decorator Pattern

**Purpose:** Attach additional responsibilities to an object dynamically.

**Agentic Use Case:** Add features to agent responses (validation, logging, caching, etc.)

``` python

# ============================================
# DECORATOR PATTERN - AGENT RESPONSE ENHANCEMENT
# ============================================

from abc import ABC, abstractmethod
from typing import Callable
import time
import hashlib
class ResponseHandler(ABC):
    @abstractmethod
    def handle(self, prompt: str) -> str:
        pass

class BasicResponseHandler(ResponseHandler):
    """Base implementation"""
    
    def handle(self, prompt: str) -> str:
        return f"Response to: {prompt}"

# Decorators - add functionality
class LoggingDecorator(ResponseHandler):
    def __init__(self, handler: ResponseHandler):
        self.handler = handler
    
    def handle(self, prompt: str) -> str:
        print(f"[LOG] Handling prompt: {prompt[:50]}...")
        response = self.handler.handle(prompt)
        print(f"[LOG] Response generated: {len(response)} chars")
        return response

class CachingDecorator(ResponseHandler):
    def __init__(self, handler: ResponseHandler):
        self.handler = handler
        self.cache = {}
    
    def handle(self, prompt: str) -> str:
        # Create cache key from prompt
        key = hashlib.md5(prompt.encode()).hexdigest()
        
        if key in self.cache:
            print("[CACHE] Cache hit!")
            return self.cache[key]
        
        print("[CACHE] Cache miss - generating response")
        response = self.handler.handle(prompt)
        self.cache[key] = response
        return response

class ValidationDecorator(ResponseHandler):
    def __init__(self, handler: ResponseHandler):
        self.handler = handler
    
    def handle(self, prompt: str) -> str:
        if not prompt or len(prompt)  str:
        start = time.time()
        response = self.handler.handle(prompt)
        duration = time.time() - start
        
        print(f"[TIMING] Completed in {duration:.3f} seconds")
        return response

class SafetyDecorator(ResponseHandler):
    def __init__(self, handler: ResponseHandler):
        self.handler = handler
        self.dangerous_keywords = ["delete", "drop", "remove", "execute"]
    
    def handle(self, prompt: str) -> str:
        for keyword in self.dangerous_keywords:
            if keyword.lower() in prompt.lower():
                return f"[SAFETY] Blocked dangerous operation: {keyword}"
        
        return self.handler.handle(prompt)

# Usage - Stack decorators
handler = BasicResponseHandler()
# Add validation
handler = ValidationDecorator(handler)
# Add safety checks
handler = SafetyDecorator(handler)
# Add logging
handler = LoggingDecorator(handler)
# Add caching
handler = CachingDecorator(handler)
# Add timing
handler = TimingDecorator(handler)
# Use it
print(handler.handle("What is machine learning?"))
print("\n---\n")
print(handler.handle("What is machine learning?"))  # From cache
print("\n---\n")
print(handler.handle("delete everything"))  # Blocked by safety
```

### 10. Facade Pattern

**Purpose:** Provide unified interface to complex subsystems.

**Agentic Use Case:** Simple interface for complex agent operations

``` python

# ============================================
# FACADE PATTERN - SIMPLIFIED AGENT INTERFACE
# ============================================

from abc import ABC, abstractmethod
# Complex subsystems
class DatabaseService:
    def query(self, sql: str) -> list:
        return [{"result": "data"}]
    
    def save(self, data: dict):
        print(f"Saved to DB: {data}")

class LLMService:
    def generate(self, prompt: str) -> str:
        return f"Generated response for: {prompt}"

class ValidationService:
    def validate_input(self, text: str) -> bool:
        return len(text) > 0
    
    def validate_output(self, text: str) -> bool:
        return len(text) > 0

class LoggingService:
    def log(self, message: str):
        print(f"[LOG] {message}")
    
    def log_error(self, error: str):
        print(f"[ERROR] {error}")

class CachingService:
    def __init__(self):
        self.cache = {}
    
    def get(self, key: str):
        return self.cache.get(key)
    
    def set(self, key: str, value):
        self.cache[key] = value

# Facade - simplifies complex interactions
class AgentFacade:
    """Simple unified interface for agent operations"""
    
    def __init__(self):
        self.db = DatabaseService()
        self.llm = LLMService()
        self.validator = ValidationService()
        self.logger = LoggingService()
        self.cache = CachingService()
    
    def process_query(self, user_query: str) -> str:
        """One simple method handles everything"""
        
        # Input validation
        if not self.validator.validate_input(user_query):
            self.logger.log_error("Invalid input")
            return ""
        
        self.logger.log(f"Processing query: {user_query}")
        
        # Check cache
        cached = self.cache.get(user_query)
        if cached:
            self.logger.log("Cache hit")
            return cached
        
        # Generate response
        try:
            response = self.llm.generate(user_query)
            
            # Validate output
            if not self.validator.validate_output(response):
                self.logger.log_error("Invalid output")
                return ""
            
            # Save to database
            self.db.save({"query": user_query, "response": response})
            
            # Cache result
            self.cache.set(user_query, response)
            
            self.logger.log("Query processed successfully")
            return response
        
        except Exception as e:
            self.logger.log_error(str(e))
            return ""

# Usage - Simple!
agent = AgentFacade()
result = agent.process_query("What is AI?")
print(f"Result: {result}")
result = agent.process_query("What is AI?")  # Uses cache
print(f"Result: {result}")
```

``` python
# ============================================

from typing import Dict

class LLMInstance:
    """Flyweight - shared LLM instance"""
    
    def __init__(self, model_name: str, parameters: dict):
        self.model_name = model_name
        self.parameters = parameters
        print(f"Creating LLM instance: {model_name} (memory: ~2GB)")

        self.llm = LLMFactory.get_llm(model_name)
```

### 12. Proxy Pattern

**Purpose:** Control access to another object.

**Agentic Use Case:** Control access to expensive LLM calls

``` python

# ============================================
# PROXY PATTERN - CONTROLLED ACCESS
# ============================================

from abc import ABC, abstractmethod
from datetime import datetime, timedelta
class LLM(ABC):
    @abstractmethod
    def generate(self, prompt: str) -> str:
        pass

class RealLLM(LLM):
    """Expensive real LLM"""
    
    def __init__(self):
        self.call_count = 0
    
    def generate(self, prompt: str) -> str:
        self.call_count += 1
        return f"[Real LLM Response #{self.call_count}] {prompt[:30]}..."

class LLMProxy(LLM):
    """Proxy to control access to RealLLM"""
    
    def __init__(self, real_llm: RealLLM, rate_limit: int = 5):
        self.real_llm = real_llm
        self.rate_limit = rate_limit
        self.call_count = 0
        self.reset_time = datetime.now() + timedelta(minutes=1)
        self.cache = {}
    
    def generate(self, prompt: str) -> str:
        # Check cache first
        if prompt in self.cache:
            print("[PROXY] Cache hit!")
            return self.cache[prompt]
        
        # Check rate limit
        if datetime.now() > self.reset_time:
            self.call_count = 0
            self.reset_time = datetime.now() + timedelta(minutes=1)
        
        if self.call_count >= self.rate_limit:
            return "[PROXY] Rate limit exceeded. Try again later."
        
        # Check cost (mock)
        if self._is_expensive_query(prompt):
            print("[PROXY] Expensive query - use simpler approach")
            return self._simple_response(prompt)
        
        # Forward to real LLM
        print("[PROXY] Forwarding to real LLM")
        self.call_count += 1
        response = self.real_llm.generate(prompt)
        
        # Cache response
        self.cache[prompt] = response
        
        return response
    
    def _is_expensive_query(self, prompt: str) -> bool:
        expensive_keywords = ["analyze", "research", "comprehensive"]
        return any(word in prompt.lower() for word in expensive_keywords)
    
    def _simple_response(self, prompt: str) -> str:
        return f"[Simple Response] {prompt[:30]}..."

# Usage
real_llm = RealLLM()
proxy = LLMProxy(real_llm, rate_limit=3)
# Cached response
print(proxy.generate("What is AI?"))
print(proxy.generate("What is AI?"))  # From cache
# Expensive query handled specially
print(proxy.generate("Comprehensive analysis of AI"))
# Rate limiting
for i in range(5):
    print(proxy.generate(f"Query {i}"))
```

### 13. Chain of Responsibility Pattern

**Purpose:** Pass request along a chain of handlers.

**Agentic Use Case:** Agent handling escalation chain

``` python

# ============================================
# CHAIN OF RESPONSIBILITY - HANDLER CHAIN
# ============================================

from abc import ABC, abstractmethod
from enum import Enum
class QueryType(Enum):
    SIMPLE = 1
    TECHNICAL = 2
    COMPLEX = 3
    URGENT = 4

class Query:
    def __init__(self, text: str, query_type: QueryType):
        self.text = text
        self.query_type = query_type
        self.handled = False

class Handler(ABC):
    def __init__(self):
        self.next_handler = None
    
    def set_next(self, handler: "Handler") -> "Handler":
        self.next_handler = handler
        return handler
    
    @abstractmethod
    def handle(self, query: Query) -> str:
        pass

class SimpleQueryHandler(Handler):
    """Handles simple queries"""
    
    def handle(self, query: Query) -> str:
        if query.query_type == QueryType.SIMPLE:
            print("[SimpleQueryHandler] Handling simple query")
            query.handled = True
            return f"Simple response to: {query.text}"
        
        if self.next_handler:
            return self.next_handler.handle(query)
        
        return "No handler found"

class TechnicalQueryHandler(Handler):
    """Handles technical queries"""
    
    def handle(self, query: Query) -> str:
        if query.query_type == QueryType.TECHNICAL:
            print("[TechnicalQueryHandler] Handling technical query")
            query.handled = True
            return f"Technical analysis: {query.text}"
        
        if self.next_handler:
            return self.next_handler.handle(query)
        
        return "No handler found"

class ComplexQueryHandler(Handler):
    """Handles complex queries"""
    
    def handle(self, query: Query) -> str:
        if query.query_type == QueryType.COMPLEX:
            print("[ComplexQueryHandler] Handling complex query")
            query.handled = True
            return f"Deep research: {query.text}"
        
        if self.next_handler:
            return self.next_handler.handle(query)
        
        return "No handler found"

class UrgentQueryHandler(Handler):
    """Handles urgent queries - highest priority"""
    
    def handle(self, query: Query) -> str:
        if query.query_type == QueryType.URGENT:
            print("[UrgentQueryHandler] PRIORITY: Handling urgent query")
            query.handled = True
            return f"URGENT RESPONSE: {query.text}"
        
        if self.next_handler:
            return self.next_handler.handle(query)
        
        return "No handler found"

# Setup chain
urgent = UrgentQueryHandler()
complex_h = ComplexQueryHandler()
technical = TechnicalQueryHandler()
simple = SimpleQueryHandler()
urgent.set_next(complex_h).set_next(technical).set_next(simple)
# Process queries
queries = [
    Query("What is AI?", QueryType.SIMPLE),
    Query("How to implement CNN?", QueryType.TECHNICAL),
    Query("Design entire AI system", QueryType.COMPLEX),
    Query("CRITICAL: System down!", QueryType.URGENT),
```

``` python
from typing import List
from datetime import datetime

        return self.agent.clear_memory()

        self.agent.memory = self.backup
```

``` python
# ============================================
# MEDIATOR PATTERN - AGENT COORDINATION
# ============================================

from abc import ABC, abstractmethod
from typing import Dict
class Mediator(ABC):
    @abstractmethod
    def send_message(self, sender: str, receiver: str, message: str):
        pass

class ConcreteMediator(Mediator):
    """Coordinates communication between agents"""
    
    def __init__(self):
        self.agents: Dict[str, "Agent"] = {}
        self.message_log: list = []
    
    def register_agent(self, agent: "Agent"):
        self.agents[agent.name] = agent
        agent.set_mediator(self)
    
    def send_message(self, sender: str, receiver: str, message: str):
        if receiver not in self.agents:
            print(f"[MEDIATOR] {receiver} not found!")
            return
        
        self.message_log.append({
            "from": sender,
            "to": receiver,
            "message": message
        })
        
        print(f"[MEDIATOR] {sender} -> {receiver}: {message[:50]}...")
        self.agents[receiver].receive_message(sender, message)
    
    def broadcast(self, sender: str, message: str):
        """Send message to all agents"""
        for agent_name, agent in self.agents.items():
            if agent_name != sender:
                self.send_message(sender, agent_name, message)

class Agent:
    def __init__(self, name: str):
        self.name = name
        self.mediator = None
        self.inbox = []
    
    def set_mediator(self, mediator: Mediator):
        self.mediator = mediator
    
    def send(self, receiver: str, message: str):
        self.mediator.send_message(self.name, receiver, message)
    
    def broadcast(self, message: str):
        self.mediator.broadcast(self.name, message)
    
    def receive_message(self, sender: str, message: str):
        self.inbox.append((sender, message))
        self.process_message(sender, message)
    
    def process_message(self, sender: str, message: str):
        print(f"  [{self.name}] Processing message from {sender}")

coding_agent = Agent("CodeBot")
writing_agent = Agent("WriterBot")
# Register agents
```

``` python
            agent.restore_from_memento(snapshot)
```

``` python
# ============================================
# OBSERVER PATTERN - EVENT SYSTEM (EXTENDED)
# ============================================

from abc import ABC, abstractmethod
from typing import List
from datetime import datetime
class Event:
    def __init__(self, event_type: str, source: str, data: dict):
        self.event_type = event_type
        self.source = source
        self.data = data
        self.timestamp = datetime.now()

class Observer(ABC):
    @abstractmethod
    def update(self, event: Event):
        pass

class LoggingObserver(Observer):
    def update(self, event: Event):
        print(f"[LOG] {event.timestamp.isoformat()} - {event.event_type} from {event.source}")

class MetricsObserver(Observer):
    def __init__(self):
        self.metrics = {
            "total_events": 0,
            "events_by_type": {}
        }
    
    def update(self, event: Event):
        self.metrics["total_events"] += 1
        
        if event.event_type not in self.metrics["events_by_type"]:
            self.metrics["events_by_type"][event.event_type] = 0
        
        self.metrics["events_by_type"][event.event_type] += 1
    
    def show_metrics(self):
        print(f"Total events: {self.metrics['total_events']}")
        for event_type, count in self.metrics["events_by_type"].items():
            print(f"  {event_type}: {count}")

class PersistenceObserver(Observer):
    def __init__(self):
        self.event_history = []
    
    def update(self, event: Event):
        self.event_history.append({
            "type": event.event_type,
            "source": event.source,
            "data": event.data,
            "timestamp": event.timestamp.isoformat()
        })

class Subject:
    def __init__(self):
        self.observers: List[Observer] = []
    
    def attach(self, observer: Observer):
        self.observers.append(observer)
    
    def detach(self, observer: Observer):
        self.observers.remove(observer)
    
    def notify(self, event: Event):
        for observer in self.observers:
            observer.update(event)

class AgentWithObserver(Subject):
    def __init__(self, name: str):
        super().__init__()
        self.name = name
    
    def process_query(self, query: str):
        self.notify(Event("query_received", self.name, {"query": query}))
        # Process...
        self.notify(Event("query_processing", self.name, {"status": "processing"}))
        # Generate response...
        self.notify(Event("response_generated", self.name, {"response": "answer"}))

# Usage
agent = AgentWithObserver("ResearchBot")
# Attach observers
logger = LoggingObserver()
metrics = MetricsObserver()
persistence = PersistenceObserver()
agent.attach(logger)
agent.attach(metrics)
agent.attach(persistence)
```

``` python
from enum import Enum
class WorkflowState(ABC):

    def process(self, agent, data):

        agent.transition_to(ReadyState())
        return "Initialized"
    
    def on_exit(self, agent):
        print(f"[INIT] Exit initialization")

    def on_enter(self, agent):
        print(f"[READY] {agent.name} is ready")
    
    def process(self, agent, data):
        if data == "quit":
            agent.transition_to(ShutdownState())
            return "Shutting down"
        
        agent.transition_to(ProcessingState())
        return "Processing started"
    
    def on_exit(self, agent):
        pass

class ProcessingState(WorkflowState):
    def on_enter(self, agent):
        print(f"[PROCESSING] {agent.name} processing request")
    
    def process(self, agent, data):
        result = agent.generate_response(data)
        agent.transition_to(ReadyState())
        return result
    
    def on_exit(self, agent):
        print(f"[PROCESSING] Completed")

class ErrorState(WorkflowState):
    def on_enter(self, agent):
        print(f"[ERROR] {agent.name} encountered error")
    
    def process(self, agent, data):
        agent.log_error(data)
        agent.transition_to(ReadyState())
        return "Error logged, ready for retry"
    
    def on_exit(self, agent):
        pass

class ShutdownState(WorkflowState):
    def on_enter(self, agent):
        print(f"[SHUTDOWN] {agent.name} shutting down")
    
    def process(self, agent, data):
        return "Shutdown complete"
    
    def on_exit(self, agent):
        agent.cleanup()

        self.state.on_enter(self)

        self.state.on_exit(self)
        self.state = state
        state.on_enter(self)
```

### 22. Visitor Pattern

``` python
# ============================================
# VISITOR PATTERN - ANALYZE CONVERSATIONS
# ============================================

from abc import ABC, abstractmethod
from typing import List
class Message:
    def __init__(self, role: str, content: str, timestamp: str):
        self.role = role
        self.content = content
        self.timestamp = timestamp
    
    def accept(self, visitor: "MessageVisitor"):
        visitor.visit_message(self)

class Conversation:
    def __init__(self, conversation_id: str):
        self.conversation_id = conversation_id
        self.messages: List[Message] = []
    
    def add_message(self, message: Message):
        self.messages.append(message)
    
    def accept(self, visitor: "ConversationVisitor"):
        visitor.visit_conversation(self)

class MessageVisitor(ABC):
    @abstractmethod
    def visit_message(self, message: Message):
        pass

class ConversationVisitor(ABC):
    @abstractmethod
    def visit_conversation(self, conversation: Conversation):
        pass

class LengthAnalyzer(ConversationVisitor):
    def visit_conversation(self, conversation: Conversation):
        total_chars = 0
        for message in conversation.messages:
            total_chars += len(message.content)
        
        print(f"[LENGTH] Conversation {conversation.conversation_id}: {total_chars} chars")

class SentimentAnalyzer(ConversationVisitor):
    def visit_conversation(self, conversation: Conversation):
        sentiments = {"positive": 0, "negative": 0, "neutral": 0}
        
        for message in conversation.messages:
            sentiment = self._analyze(message.content)
            sentiments[sentiment] += 1
        
        print(f"[SENTIMENT] {conversation.conversation_id}: {sentiments}")
    
    def _analyze(self, text: str) -> str:
        positive_words = ["good", "great", "excellent", "happy"]
        negative_words = ["bad", "awful", "terrible", "sad"]
        
        text_lower = text.lower()
        
        pos_count = sum(1 for word in positive_words if word in text_lower)
        neg_count = sum(1 for word in negative_words if word in text_lower)
        
        if pos_count > neg_count:
            return "positive"
        elif neg_count > pos_count:
            return "negative"
        return "neutral"

class TopicExtractor(ConversationVisitor):
    def visit_conversation(self, conversation: Conversation):
        topics = set()
        
        for message in conversation.messages:
            extracted = self._extract_topics(message.content)
            topics.update(extracted)
        
        print(f"[TOPICS] {conversation.conversation_id}: {topics}")
    
    def _extract_topics(self, text: str) -> List[str]:
        keywords = ["AI", "ML", "Python", "data", "model", "algorithm"]
        return [k for k in keywords if k.lower() in text.lower()]

class StatisticsCollector(ConversationVisitor):
    def visit_conversation(self, conversation: Conversation):
        user_msgs = sum(1 for m in conversation.messages if m.role == "user")
        assistant_msgs = sum(1 for m in conversation.messages if m.role == "assistant")
        avg_length = sum(len(m.content) for m in conversation.messages) / len(conversation.messages)
        
        print(f"[STATS] {conversation.conversation_id}:")
        print(f"  User messages: {user_msgs}")
        print(f"  Assistant messages: {assistant_msgs}")
        print(f"  Avg message length: {avg_length:.0f} chars")

# Usage
conversation = Conversation("conv_001")
conversation.add_message(Message("user", "Tell me about AI", "2024-01-01"))
conversation.add_message(Message("assistant", "AI is great technology", "2024-01-01"))
conversation.add_message(Message("user", "How does ML algorithm work?", "2024-01-01"))
conversation.add_message(Message("assistant", "ML is excellent for data processing", "2024-01-01"))
# Apply different visitors
conversation.accept(LengthAnalyzer())
conversation.accept(SentimentAnalyzer())
conversation.accept(TopicExtractor())
conversation.accept(StatisticsCollector())
```

### 23. Interpreter Pattern (Bonus Behavioral)

**Purpose:** Define grammar and interpreter for language.

**Agentic Use Case:** Parse and execute agent commands

``` python

# ============================================
# INTERPRETER PATTERN - COMMAND LANGUAGE
# ============================================

from abc import ABC, abstractmethod
class Expression(ABC):
    @abstractmethod
    def interpret(self, context: dict) -> str:
        pass

class LiteralExpression(Expression):
    def __init__(self, value: str):
        self.value = value
    
    def interpret(self, context: dict) -> str:
        return self.value

class VariableExpression(Expression):
    def __init__(self, name: str):
        self.name = name
    
    def interpret(self, context: dict) -> str:
        return context.get(self.name, f"undefined_{self.name}")

class SetExpression(Expression):
    def __init__(self, var_name: str, value_expr: Expression):
        self.var_name = var_name
        self.value_expr = value_expr
    
    def interpret(self, context: dict) -> str:
        value = self.value_expr.interpret(context)
        context[self.var_name] = value
        return f"Set {self.var_name} = {value}"

class IfExpression(Expression):
    def __init__(self, condition: str, then_expr: Expression, else_expr: Expression = None):
        self.condition = condition
        self.then_expr = then_expr
        self.else_expr = else_expr
    
    def interpret(self, context: dict) -> str:
        if self.condition == "true" or context.get(self.condition):
            return self.then_expr.interpret(context)
        elif self.else_expr:
            return self.else_expr.interpret(context)
        return "Condition false"

class PrintExpression(Expression):
    def __init__(self, var_expr: Expression):
        self.var_expr = var_expr
    
    def interpret(self, context: dict) -> str:
        value = self.var_expr.interpret(context)
        print(f"[OUTPUT] {value}")
        return f"Printed: {value}"

class CommandInterpreter:
    """Simple interpreter for agent commands"""
    
    def __init__(self):
        self.context = {}
    
    def interpret_command(self, command: str) -> str:
        # Parse simple commands
        if command.startswith("SET"):
            parts = command.split()
            # SET name value
            var_name = parts[1]
            value = parts[2] if len(parts) > 2 else ""
            expr = SetExpression(var_name, LiteralExpression(value))
            return expr.interpret(self.context)
        
        elif command.startswith("PRINT"):
            parts = command.split()
            var_name = parts[1] if len(parts) > 1 else ""
            expr = PrintExpression(VariableExpression(var_name))
            return expr.interpret(self.context)
        
        elif command.startswith("GET"):
            parts = command.split()
            var_name = parts[1] if len(parts) > 1 else ""
            return VariableExpression(var_name).interpret(self.context)
        
        return "Unknown command"

# Usage
interpreter = CommandInterpreter()
commands = [
    "SET name Alice",
    "SET age 30",
    "PRINT name",
    "PRINT age",
    "GET name",
]
for cmd in commands:
    result = interpreter.interpret_command(cmd)
    print(f"$ {cmd}")
    print(f"  Result: {result}\n")
```

### When to Use Each Pattern

### Quick Decision Tree

``` python

Need to CREATE objects?
├─ How many variations? 
│  ├─ One method per type → Factory Method
│  ├─ Families of related objects → Abstract Factory
│  ├─ Complex step-by-step → Builder
│  ├─ Clone existing → Prototype
│  └─ Single global instance → Singleton
```

``` python

Need to COMPOSE objects?
├─ Different interfaces?
│  ├─ Adapt incompatible interfaces → Adapter
│  ├─ Decouple abstraction/impl → Bridge
│  ├─ Tree structures → Composite
│  ├─ Add features dynamically → Decorator
│  ├─ Simplify complex subsystem → Facade
│  ├─ Share common state → Flyweight
│  └─ Control access → Proxy
```

``` python

Need to DEFINE algorithms/interactions?
├─ Objects communicate?
│  ├─ Pass along chain → Chain of Responsibility
│  ├─ Encapsulate requests → Command
│  ├─ Access sequentially → Iterator
│  ├─ Coordinate objects → Mediator
│  ├─ Save/Restore state → Memento
│  ├─ Notify observers → Observer
│  ├─ Change behavior by state → State
│  ├─ Interchangeable algorithms → Strategy
│  ├─ Algorithm skeleton → Template Method
│  └─ Perform on elements → Visitor
```

### Conclusion

You now have practical examples of **all 23 Gang of Four design patterns** applied to agentic Python applications. Key takeaways:

1.  **Creational patterns** handle flexible object creation
2.  **Structural patterns** organize complex object relationships
3.  **Behavioral patterns** manage object communication and responsibilities

Start with the most relevant patterns for your use case and build from there. Overusing patterns creates complexity; using them judiciously creates elegant systems.
